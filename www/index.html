Bounded Posit RPN

Keyboard: digits, . e, + - * /, Enter, Backspace (drops X when not typing), n change sign, s swap X and Y, Esc clear, Delete same as Backspace. - is always subtract; use n to change sign. Not on the keypad but still bound: r reciprocal, d double, h halve. Type 0x7f or 0b0110 for a raw bit pattern.

Arithmetic by fast-posit (LGPL-3.0). Parameters follow BPosits.jl. Source.
